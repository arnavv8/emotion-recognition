# Training Metrics

This directory contains training metrics and visualizations generated during model training:

## Audio Model
- `audio_confusion_matrix.png`: Confusion matrix for audio emotion classification
- `audio_training_curves.png`: Loss and accuracy curves during training
- `audio_classification_report.json`: Detailed classification metrics

## Video Model
- `video_confusion_matrix.png`: Confusion matrix for video emotion classification
- `video_training_curves.png`: Loss and accuracy curves during training
- `video_classification_report.json`: Detailed classification metrics
